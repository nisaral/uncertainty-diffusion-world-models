Uncertainty-diffusion world models · toy laboratory

Decision-aware distillation does not identify epistemic uncertainty

Four students, one 2-D (w, g) field, one click. The map is aleatoric-dominated (g* ≫ w*), the regime measured on DelayedBimodal and hopper-hop. This is a laboratory for a loss, not a SOTA agent — it does not win control.

Not a deployed policy. Nothing here is a robot, an LLM agent, or a return claim. Use it the way an Infoprop / MACURA user should: inspect teacher–student u-rank before trusting a distilled student to gate imagination.

1. Train the four losses

ordinary matches member means (ranking usually holds). hybrid matches one mixed scalar — the M=1 fibre; it can walk w → 0. identified_eq matches (w, g) with equal weights. identified_ema uses inverse-variance EMA weights; on this map the aleatoric term is numerically dead.

Idle — press train.
low |u| (less uncertain) high |u| (more uncertain) Heatmaps are teacher vs student u = w − g. Rank-only: do not read the color scale as calibrated magnitude.

2. Rank correlation over training

Spearman of teacher u vs student u. EMA goes to noise. Equal-weight recovers ranking. Ordinary holds. Hybrid walks the fibre.

3. Gate preview — would Infoprop / MACURA trust this student?

Percentile-0.85 stop on |u|. Green = agree keep, slate = agree stop, red = over-keep (student trusts a state the teacher would refuse), orange = under-keep. This is the composition failure in miniature: a different gate on a destroyed object does not fix ranking.
